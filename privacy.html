Privacy Policy - NeonTube

Last updated: 20 November 2026

NeonTube is a private desktop app used by me (sheikhhuzaima7) on my own computer to manage my own YouTube channel(s). This page explains what data the app uses and how.

What data NeonTube uses

  • My Google account email and basic profile, only to show which account is signed in.
  • My YouTube channel information, videos, playlists and upload settings, to upload and schedule my own videos.
  • My YouTube Analytics data (views, watch time, audience), to plan better videos.

How the data is used

The data is used only inside the NeonTube app on my own computer, only for my own channel(s). It is not used for advertising and it is not sold.

Where the data is stored

Sign-in tokens and settings are saved only on my own computer. The app talks directly to Google's YouTube services.

Sharing

NeonTube does not share, sell or transfer Google user data to any third party.

Google API Services User Data Policy

NeonTube's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

NeonTube uses YouTube API Services. By using it, you agree to the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be removed at any time from Google Account permissions.
